# 마케팅 성과 측정 대시보드

여프쿠폰 마케팅 채널별 성과를 관리하는 로컬 우선 대시보드입니다.

현재는 YouTube Studio 프로모션 대시보드만 활성화되어 있으며, 이후 Naver Ads, Google Ads, Meta Ads 등 채널별 대시보드를 같은 구조로 확장합니다.

## 현재 실행 방식

별도 빌드 없이 `index.html`을 브라우저에서 열면 실행됩니다.

- 화면 마크업: `index.html`
- 앱 로직: `src/app.js`
- 전역 스타일: `src/styles/app.css`
- 브랜드 이미지: `assets/brand/`
- 브라우저 저장 데이터: `localStorage`

## 설계 원칙

- 기존 데이터 키를 바꾸지 않습니다.
- 채널별 저장소, 렌더러, 지표 정의는 분리 가능한 구조로 유지합니다.
- 대시보드 UI는 운영자가 매일 확인하기 좋은 밀도와 가독성을 우선합니다.
- 시각화와 테이블은 실제 의사결정에 필요한 지표부터 확장합니다.
- 큰 프레임워크 도입은 필요가 생긴 시점에 진행합니다.
